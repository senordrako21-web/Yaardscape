# Yardscape Landscaping & Beautification Services

GitHub Pages-ready front end plus Google Apps Script booking backend.

**Start here:** read `SETUP.md` in order. Configure the Google Sheet and Apps Script first, paste the deployed `/exec` URL into `config.js`, then publish the files to the root of your GitHub Pages repository.

No admin key or spreadsheet ID belongs in this repository. See `SETUP.md` for the exact setup and end-to-end test procedure.
